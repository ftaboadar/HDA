# Actividades por miembro del equipo

Cada persona agrega su propia entrada como parte de su propio Pull Request (ver sección 1.2 de
`experimento-arquitectura/contexto/12-plan-entrega-4.md`). Es el testimonio individual de qué hizo
cada quien — no se genera con IA en nombre de otra persona.

Formato de cada entrada:

```markdown
## [Tu nombre]
- Microservicio(s) a cargo: ...
- Qué implementé: ...
- Cómo colaboré con el resto del equipo: ...
```
