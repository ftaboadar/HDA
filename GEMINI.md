# Hogar de los Alpes — Gemini CLI

Ver **`AGENTS.md`** primero — es la guía de orientación del proyecto, escrita para cualquier
asistente de IA (Claude Code, Gemini CLI, Codex CLI, u otro) que abra este repo. Aplica igual aquí;
no la dupliques ni la reescribas en este archivo.

## Específico de Gemini CLI

Este repo no tiene extensiones/personas nativas de Gemini CLI configuradas — no se generaron porque
no se pudo verificar contra una instalación real cuál es el formato vigente en este momento. Los 6
roles de equipo siguen siendo markdown plano en `.claude/agents/*.md`: ábrelos y sigue sus
instrucciones como si fueran tu prompt para esa tarea (ver la sección correspondiente en
`AGENTS.md`). Si tu versión de Gemini CLI sí soporta registrar personas/extensiones nativas y el
equipo quiere esa integración más profunda, se puede añadir después sin tocar el contenido de los
roles — solo un archivo de registro adicional que apunte a los mismos `.md`.
